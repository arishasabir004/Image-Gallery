# Image Gallery

A responsive **Image Gallery** built using **HTML, CSS, and JavaScript** as part of the **CodeAlpha Frontend Development Internship**.

##  Project Overview

This project is a modern image gallery that displays images in a clean grid layout. It includes category filters, hover effects, a lightbox preview, and next/previous navigation for a better user experience.

##  Features

* Responsive image gallery layout
* Category-based image filtering
* Hover effects with smooth transitions
* Lightbox image preview
* Next / Previous navigation inside lightbox
* Keyboard support for image navigation
* Mobile-friendly design

##  Technologies Used

* **HTML5** – page structure
* **CSS3** – styling, layout, responsiveness, animations
* **JavaScript** – filtering logic, lightbox functionality, navigation

##  Folder Structure

```bash
Gallery/

│   ├── animal2.jpg
│   ├── animal3.jpg
```

##  How to Run the Project

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Make sure all image files are inside the `images` folder.
4. Open `index.html` using **Live Server**.

##  Functionalities

* **Filter Buttons:** Show images by category such as Nature, City, or Animals
* **Lightbox Preview:** Click an image to open it in full preview mode
* **Navigation:** Use next/previous buttons or keyboard arrows to switch images
* **Close Option:** Close lightbox using the close icon or `Esc` key
